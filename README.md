# This is the part of Atomic AI Bot project.

React-AI-ChatBot-WebServiceFrontend

### Technologies
- Node.js 20+ - runtime
- React - UI library
- Vite - dev server and production build
- React Router DOM - client-side routing
- Tailwind CSS - styling
- ESLint - linting

### Commands
1. Install dependencies
```bash
npm install
```

2. Add `.env` file with the same variables as in `.env.example`

3. Run frontend project
- development mode
```bash
npm run dev
```
Backend API should be available at `http://127.0.0.1:8000` (see backend README).

- production mode (static build + local preview)
```bash
npm run build
npm run preview
```
